## Resumo
Neste trabalho desenvolvi, em Python, uma aplicação de gestão de uma turma de alunos com um menu interativo.
A aplicação permite criar uma turma, inserir alunos, listar a turma e consultar um aluno pelo seu id. Permite também guardar a turma num ficheiro de texto e carregá-la de novo.
Cada aluno é representado por um tuplo (nome, id, [notaTPC, notaProj, notaTeste]), e a turma por uma lista desses tuplos.
Para a realização do mesmo, utilizei ciclos for e while, condições, funções, listas, tuplos e leitura e escrita de ficheiros.
