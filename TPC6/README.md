## Resumo
Neste trabalho desenvolvi, em Python, uma aplicação de análise de dados meteorológicos com um menu interativo.
A aplicação permite calcular médias, amplitudes e valores extremos, listar dias e desenhar gráficos. Permite também guardar a tabela num ficheiro de texto e carregá-la de novo.
Cada dia é representado por um tuplo ((ano, mês, dia), tmin, tmax, prec), e a tabela por uma lista desses tuplos.
Para este trabalho utilizei ciclos, condições, funções, listas, tuplos, ficheiros e funções matplotlib.
