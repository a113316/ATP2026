## Resumo
Neste trabalho o objetivo era criar um jogo em Python com duas modalidades: o computador pensa num número e o utilizador tenta adivinhar ou o utilizador pensa num número e o computador tenta adivinhar. Para isto recorri às seguintes ferramentas de linguagem Python: funções (def) para separar as duas modalidades criadas em blocos independentes, ciclos (while) para repetir os pedidos do palpite até o número ser adivinhado e estruturas "if/else" para comparar os palpites com o número pensado e perceber se era maior, menor ou igual ao valor suposto. Na primeira modalidade utilizei também o módulo "random" para fazer com que o computador gerasse aleatoriamente um número de 0 a 100. Finalmente usei também o "print" para mostrar as mensagens do jogo e número de tentativas usadas no mesmo, tal como pedido. 
Para a modalidade 2, na qual o computador adivinha, recorri à pesquisa binária, isto é, o computador arrisca sempre o valor exatamente no meio do intervalo fornecido. Como o intervalo é sempre reduzido a metade, o computador consegue sempre adivinhar qualquer número em 7 tentativas, no máximo.
