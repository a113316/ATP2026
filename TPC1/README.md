## Resumo
Neste trabalho foi resolvido o último nível do jogo Maze, no Blockly Games, aplicando os conceitos de programação por blocos para guiar o personagem até ao objetivo final, tendo em conta as estruturas de repetição e condição necessárias para completar o percurso.

Foi-me também pedido para construirr um desenho de um barco utilizando o Turtle, também no Blockly Games. Para além do barco, o desenho incluiu um sol, ondas e nuvens, o que exigiu o uso de diferentes técnicas de desenho de forma a combinar várias formas geométricas num único desenho coerente.
