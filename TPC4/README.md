## Resumo
O presente trabalho teve como objetivo o desenvolvimento, em Python, de uma aplicação interativa baseada em menu para a gestão de uma lista de números. A aplicação permite criar uma lista aleatória ou introduzida pelo utilizador, calcular a soma, a média, o maior e o menor elemento, verificar se a lista se encontra ordenada por ordem crescente ou decrescente e procurar a posição de um elemento. Com este exercício, foi possível consolidar a utilização de funções, listas e ciclos, bem como a reutilização dos resultados das funções num programa estruturado em menu.
